🪜 Changes

Promotion / demotion ladders, one per type (staff, builder, ...). Each type has its own role ladder and its own announce channel. Rung #0 is always the base rank (your Member role); every role you add goes on top. Used by /promote, /demote and accepted applications linked to a type. Each type can also hand out extra roles (like a "Staff Team" role) when someone joins its ladder.

Hold Ctrl / Cmd to pick several (max {{ max_extras }}). Good for a "Staff Team" role or a separator role. They are added when someone goes from #0 (or no rank) up to #1 or higher, and removed when they're demoted back to #0. Moves like #1 → #2 never touch them. It's silent: the card doesn't mention them, and the command only tells you if one fails. A role shared with another type stays until the member has left both. LOA removes them too and gives them back when it ends. Only affects future changes; nobody is changed retroactively. Ladder roles can't be extras.
