⚙️ Custom Command Symbol

Default is /. You can change it to anything (?, !, etc) for text-based invocation. Slash commands (/) always keep working too.

🔐 Command Permissions

Commands are grouped like the help menus. Until a command is enabled and given roles, only Administrators can use it (new commands always start that way). Use a group's Apply to all to set every command in it at once, or open the group to set single commands. Tick 🔒 Not affected by group changes on a command (then Save) to keep it out of the group's Apply: it stays in its group and keeps its own settings.
