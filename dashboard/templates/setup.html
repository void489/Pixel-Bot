Set up Pixel Bot in minutes

Six quick steps from invite to a fully working server. You can read this now and follow along once the bot is in your server.

{% if add_bot_url %}➕ Add to Discord{% endif %} Open Dashboard
{% endif %}

  1. Add the bot and place its role

    Invite Pixel Bot to your server, then open Server Settings → Roles and drag the Pixel Bot role up.

    • The bot can only manage roles, nicknames and members that sit below its own role.
    • Put it above your staff, mute, member and ticket roles.
    This is the number one cause of "the bot isn't working". If role changes, bans or timeouts fail, check the role order first.
    {% if guild_id and add_bot_url %}Add or re-invite the bot →{% endif %}

  2. Set your log channels

    Pick a private staff channel for the bot's log, and a channel for ticket transcripts. Moderation actions, ticket events and more get recorded here.

    • Make sure the bot can View Channel, Send Messages and Embed Links there.
    • Choose which events to log, and set blacklist roles if you use them.
    {{ go('dashboard.config_logs_page', 'Config & Logs') }}

  3. Choose who can use commands

    Bot commands start out admin-only. Nothing is broken, it's a safety default. Decide which roles get which commands.

    • Enable member commands (like /serverinfo or /rank) for everyone or for specific roles.
    • Give your moderators and staff only the staff commands they need.
    If a teammate says a command "does nothing" or is missing, it almost always just needs enabling here.
    {{ go('dashboard.permissions_page', 'Command Permissions') }}

  4. Turn on your first feature

    Don't set everything up at once. Pick the one you need most, get it working, then come back for the next.

    {{ feat('dashboard.tickets_page', '🎫 Tickets', 'Create ticket types and post a panel.') }} {{ feat('dashboard.automod_page', '🛡️ Auto-Mod', 'Block spam, links and bad words.') }} {{ feat('dashboard.welcome_page', '👋 Welcome', 'Greet new members and give an auto role.') }} {{ feat('dashboard.applications_page', '📝 Applications', 'Take staff applications.') }} {{ feat('dashboard.leveling_page', '⭐ Leveling', 'XP, ranks and reward roles.') }} {{ feat('dashboard.moderation_page', '🔨 Moderation', 'Cases, warns and history.') }}

    Giveaways, polls, embeds and anti-nuke are run with slash commands. Enable them in Command Permissions, then use /giveaway create, /poll create or /embeds create.

  5. Test it like a member

    Before announcing anything, try it from a normal account or an alt, not as an admin.

    • Run /help to see what members can use. Staff can run /staffhelp, admins /admin help.
    • If you set up tickets, open one yourself and close it.
    • Check your log channel. You should see the action show up.

  6. Fine-tune and relax

    Once the basics work, customize the extras: the bot's server nickname, bio and avatar, welcome and join messages, staff tools like strikes, LOA and activity checks, and the security options.

Troubleshooting

The dropdowns on the dashboard are empty

The bot can't see your channels or roles. Check that Pixel Bot is actually in the server and has View Channels, then refresh the page.

Slash commands don't show up

Give it a minute after inviting the bot, then restart Discord. Also check that the command is enabled for your role in Command Permissions, and that the bot was invited with the applications.commands scope. Re-inviting fixes it.

The bot can't give a role, kick, ban or time someone out

Almost always role order. Move the Pixel Bot role above the target's highest role. Nobody can be moderated above the bot's role, and nobody above the server owner.

Nothing is being logged

Set a log channel in Config & Logs, make sure the event type is ticked, and check the bot can send messages and embeds in that channel.

I can't see my server in the dashboard

You need the Manage Server permission, and the bot has to be in the server. Servers without the bot are listed separately with an Add bot button.
