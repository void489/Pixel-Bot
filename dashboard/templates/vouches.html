📣 Vouch Channels

Hold Ctrl/Cmd to select several. Users type vouch @user [reason] or scam vouch @user [reason] in these channels. You can also use /vouch setchannel and /vouch removechannel.

📨 Report Channel

Reports from /report land here with Accept / Reject buttons for staff.

🛡️ Report Staff Role

Members with this role can Accept or Reject reports on the report embeds.
Who can Accept / Reject:
• Server Administrators — always allowed.
• Members with the Report Staff Role above — allowed.
• If no Report Staff Role is set — only Administrators can decide.

🎭 Scammer Role

Must be an existing role — the bot does not create it. When a report is accepted, this role is assigned in this server only. The global scammer status in the database is separate and applies to /lookup everywhere.

📖 Commands

Message triggers (only inside configured vouch channels):
vouch @user [reason]
scam vouch @user [reason]
Commands:
/vouches [user] — public vouch card
/vouches channels — list this server's vouch channels
/vouches setreportchannel <channel>
/vouches scammer add <user> — mark user as global scammer
/vouches scammer remove <user> — clear global scammer flag
/vouch setchannel <channel>
/vouch removechannel <channel>
/lookup <user> — global scammer status + cross-guild role check
/report <user> <reason> <photo1> [photo2] [photo3]
/config — configuration overview
